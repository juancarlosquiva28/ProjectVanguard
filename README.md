# PROJECT VANGUARD

**A first-person shooter built with Unreal Engine 5 and C++.**

Project Vanguard is a personal game development project focused on exploring FPS mechanics, gameplay programming, and game systems.

The goal is to progressively build a playable shooter while experimenting with different mechanics and learning more about Unreal Engine.

## Tech Stack

- **Engine:** Unreal Engine 5.8
- **Language:** C++
- **IDE:** Visual Studio 2022
- **Platform:** Windows (PC)

## Implemented Features

- [x] First-person character controller
- [x] Character movement and jumping
- [x] Sprint functionality
- [ ] Weapon and shooting system
- [ ] Health and damage system
- [ ] Enemy AI
- [ ] Weapon statistics
- [ ] Inventory and pickups
- [ ] Basic game HUD

## Development Roadmap

**Phase 1 — Core Movement**

Establish the basic player controller and movement mechanics.

**Phase 2 — Combat**

Implement weapons, shooting, damage, and health systems.

**Phase 3 — Gameplay**

Introduce enemies, interactions, pickups, and basic game objectives.

**Phase 4 — Polish**

Improve animations, visual feedback, sound effects, and overall gameplay.

## Development Status

**Early Development — Experimental Prototype**

Project Vanguard is currently under active development. Features and mechanics may change as the project evolves.
